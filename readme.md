Десктопное приложение для Windows, которое автоматически следит за выбранной Wi-Fi сетью, удерживает подключение к ней и контролирует доступ в интернет.

Живёт в системном трее и не мешает работе — пока соединение в порядке, о нём можно забыть.

Программа особенно полезна в местах с нестабильным Wi-Fi сигналом (например, за городом 
или в зонах слабого покрытия) — она самостоятельно переподключается при разрыве связи.

## Как пользоваться

При первом запуске введите SSID (имя сети) и пароль.
Далее используйте кнопки в интерфейсе для запуска/остановки мониторинга и очистки лога.
Закрытие окна сворачивает приложение в трей — для полного выхода используйте меню трея.

## Назначение

Wi-Fi Монитор решает задачу **стабильного и автоматического подключения** к конкретной Wi-Fi сети на Windows-устройстве.

**Проблема:** в местах со слабым покрытием (загородный дом, дача, удалённый офис, помещения с толстыми стенами) Wi-Fi регулярно «отваливается». Windows далеко не всегда переподключается сама, особенно если сеть на время полностью пропадает из эфира — пользователю приходится вручную кликать по значку сети, выбирать сеть и ждать.

**Решение:** компактная утилита, которая постоянно сканирует эфир на наличие нужного SSID, переподключается при разрыве, проверяет реальный доступ в интернет и показывает живой статус задержки до 8.8.8.8 — всё это из системного трея, без лишних окон и кликов.


##  Функциональность

###  Мониторинг и автоматическое переподключение
- Сканирование эфира через `netsh wlan show networks` с заданным интервалом.
- Автоматическое создание профиля сети (WPA2-PSK / AES) и подключение через `netsh wlan connect`.
- До **100 попыток переподключения** с активным ожиданием результата, без фиксированных пауз.
- Корректная работа в локалях Windows на русском и английском (распознавание маркеров «Подключено» / «Connected»).

###  Проверка интернета и пинг-монитор
- Двухуровневая проверка интернета: сначала пробуем роутер, при неудаче — DNS Google (8.8.8.8).
- Отдельный поток пинга 8.8.8.8 с настраиваемым интервалом и цветовой индикацией качества связи:
    - 🟢 **< 80 мс** — отлично
    - 🟡 **< 200 мс** — нормально
    - 🔴 **> 200 мс** — плохо
- Автодетект активного VPN (время отклика < 1 мс) с отображением «VPN is ON».

###  Системный трей
- При закрытии окна приложение **сворачивается в трей**, а не выгружается из памяти.
- Цветная иконка отражает текущее состояние подключения: 🟢 зелёная — подключено, 🔴 красная — нет соединения.
- Контекстное меню трея: «Открыть», «Выход». Двойной клик по иконке разворачивает окно.
- Всплывающая подсказка показывает текущий SSID и его статус.

###  Безопасное хранение учётных данных
- SSID и флаг «Запомнить меня» хранятся в `QSettings` (реестр Windows).
- Пароль сохраняется в **Windows Credential Manager** через библиотеку `keyring` — в открытом виде он нигде не лежит.
- Полное удаление сохранённых данных одним кликом (снять галку «Запомнить меня» при следующем запуске).

###  Настройки пользователя
- Интервал проверки Wi-Fi (1–3600 сек).
- Интервал пинга (1–3600 сек).
- IP роутера для проверки локальной сети (значение по умолчанию: `192.168.0.1`).
- Изменения применяются на лету — потоки мониторинга и пинга перезапускаются без необходимости перезагружать приложение.

###  Лог событий
- Журнал событий в главном окне с временными метками.
- **Дедупликация повторяющихся строк:** при повторе статуса обновляется только время в существующей строке.
- Автоматическое обрезание лога до **500 последних строк** для экономии памяти.
- Кнопка очистки в один клик.

##  Архитектура проекта

```
wifi-monitor-python/
├── main.py                 # Точка входа: создаёт QApplication, показывает диалоги/окно
├── build_exe.py            # Автоматическая сборка EXE через PyInstaller (+UPX)
├── WiFi_Monitor.spec       # Spec-файл PyInstaller
├── requirements.txt        # Зависимости проекта
│
├── core/                   # Бизнес-логика, без зависимостей от UI
│   ├── wifi.py             # Управление Wi-Fi через netsh, проверка интернета
│   ├── workers.py          # Фоновые QThread: MonitorThread, PingThread
│   └── settings.py         # QSettings, keyring, автозапуск (winreg)
│
├── ui/                     # Слой представления (PyQt5)
│   ├── window.py           # Главное окно и системный трей
│   ├── dialogs.py          # Диалоги ввода учётных данных и настроек
│   ├── styles.py           # Стили виджетов и константы окна
│   └── icons.py            # Фабрики иконок для трея
│
├── download/               # Готовый EXE-релиз
│   └── WiFi_Monitor_V0.3.5.exe
└── upx/                    # (опционально) UPX для сжатия EXE
```

**Разделение слоёв:** `core/` не знает о PyQt-виджетах, `ui/` не лезет в `netsh` напрямую — только через `WiFiMonitor`. Это упрощает тестирование и потенциальный порт UI на другие фреймворки.

##  Сборка, запуск и дистрибуция

### Требования к окружению
- Windows 10 / 11
- Python 3.10 или новее
- Wi-Fi адаптер, поддерживаемый Windows (используется системный `netsh wlan`)

### Быстрый запуск из исходников

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/<your-account>/wifi-monitor-python.git
   cd wifi-monitor-python
   ```

2. **Создать виртуальное окружение и установить зависимости:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Запустить:**
   ```bash
   python main.py
   ```

### Сборка EXE-файла

Сборка автоматизирована через `build_exe.py`:

```bash
python build_exe.py
```

Скрипт:
- очищает старые артефакты (`build/`, `dist/`, `__pycache__/`, `*.spec`),
- запускает PyInstaller с флагами `--onefile --windowed`,
- автоматически находит **UPX** (в `PATH` или в локальной папке `./upx/`) и подключает сжатие — итоговый EXE становится в 2–3 раза меньше,
- кладёт готовый файл в `dist/WiFi_Monitor.exe`.

Готовый сжатый бинарник версии 0.3.5 уже лежит в [`download/WiFi_Monitor_V0.3.5.exe`](download/WiFi_Monitor_V0.3.5.exe) — можно использовать сразу, без установки Python.

##  Как пользоваться

1. **Первый запуск.** Введите SSID нужной сети и пароль. Поставьте галку «Запомнить меня», чтобы при следующем запуске данные подставились автоматически (пароль шифруется в Credential Manager).
2. **Главное окно.** Мониторинг стартует сразу. В верхней части — текущий пинг до 8.8.8.8 с цветовой индикацией, в центре — журнал событий, внизу — строка состояния и кнопки управления.
3. **Кнопки управления.**
    - **Запуск мониторинга** / **Остановить** — управление фоновым потоком проверки сети.
    - **Очистить лог** — сброс журнала.
    - **Настройки** — изменение интервалов проверки и пинга на лету.
4. **Свернуть в трей.** Закрытие окна (крестик) скрывает приложение в системный трей — мониторинг продолжает работать. Для полного выхода используйте пункт «Выход» в меню трея.

##  Что нового в v0.3.5

-  **Рефакторинг в модульную структуру** (`core/` и `ui/`) — раньше всё лежало в одном файле.
-  **Окно настроек** — интервалы проверки и пинга теперь редактируются из интерфейса, без правки кода.
-  **Хранение пароля в Windows Credential Manager** через `keyring` вместо локального файла.
-  **Прерываемый sleep в QThread** — потоки останавливаются мгновенно, а не ждут окончания паузы.
-  **Дедупликация повторяющихся строк лога** и автоматическое обрезание до 500 последних записей.
-  **Поддержка локалей Windows** — корректное распознавание статуса подключения на русской и английской системе.
-  **Активное ожидание подключения** вместо фиксированной паузы — приложение быстрее реагирует на смену состояния сети.
-  **Скрипт сборки `build_exe.py`** с автоматическим подхватом UPX и очисткой артефактов.
